# Digital ID & Neural Portfolio

Interactive 3D physics digital identity card of **Vasudev Singh Jamwal** (Software Support Engineer @ GreyOrange • AI/ML & SRE), featuring real-time neural particle graphs, a dual-sided 3D card engine, contactless networking QR generation, Web Audio API haptic synthesis, and zero-dependency FakeScroll physics.

## Key Features

- **Dual-Sided 3D Card Engine (`⇄`)**: Flips seamlessly between the primary profile identity face and the contactless networking QR & telemetry terminal face.
- **Contactless Networking QR Code**: High-contrast vector QR code instantly scannable by mobile devices for contact discovery and vCard download.
- **Interactive Cyber CLI Terminal**: Live simulated Erlang node cluster health monitor and interactive command interpreter (`stack`, `fleet`, `contact`, `clear`).
- **Web Audio API Haptics**: Browser-native procedural sound synthesizer providing tactile sci-fi chimes and click feedback without external assets.
- **Telemetry HUD**: Real-time IST clock synchronization and dynamic ping/jitter simulation (`14ms`).
- **Kinetic FakeScroll System**: Floating, cursor-grabbed cyber scrollbar with edge-fade gradient masks.
- **Dynamic vCard Generation**: One-click RFC 6350 vCard export with confetti feedback.

## Technical Architecture

- **Rendering Pipeline**: HTML5 canvas neural particle mesh with dynamic distance-linked synaptic nodes.
- **Perspective Physics**: Real-time cursor coordinates transformed into 3D gyroscopic card tilt angles (`rotateX`, `rotateY`).
- **Audio Synthesis**: Multi-waveform Web Audio API oscillator chains with exponential gain ramps.
- **Export Protocols**: RFC 6350 vCard 3.0 / 4.0 compliant contactless payload.

## Core Modules

- `CanvasParticles`: Self-contained point cloud graph with smooth radial velocity displacement and dynamic alpha stroke linking.
- `FakeScrollDriver`: Direct DOM manipulation decoupling native browser scrolling from the canvas render loop.
- `AudioSynthesizer`: Zero-asset Web Audio API micro-engine with automatic browser gesture unlock.
- `CardFlipper3D`: CSS 3D perspective matrix transform preserving face visibility and state.
